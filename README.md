## בקרות באיקיו
- גרירה בעכבר על הגרף: ימין/שמאל = תדר, למעלה/למטה = Range (מקסימום הורדה)
- גלגלת עכבר = Q
- קו מקווקו לבן = מקסימום הדיכוי, עקומה צהובה/ורודה = מה שקורה עכשיו
- CENTER = תדר מרכז, NOW = כמה dB מורידים כרגע, S-PEAK = התדר החזק ביותר באזור הזיהוי
